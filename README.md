# Sample Superstore Sales Analysis Dashboard

## Project Overview
This project focuses on analyzing retail sales data using **Microsoft Power BI**. An interactive dashboard was developed to explore sales performance, profitability, product trends, customer insights, and regional performance.

The dashboard helps users understand business performance through interactive visualizations, filters, customized tooltips, and drill-through analysis.

## Objectives
- Analyze overall sales, profit, and quantity performance.
- Identify top-performing products and customers.
- Evaluate regional and segment-wise sales performance.
- Analyze monthly and yearly sales trends.
- Explore detailed product and customer performance.
- Build an interactive dashboard for business insights.

## Tools & Technologies
- Microsoft Power BI
- Power Query
- DAX
- Data Visualization

## Dataset Description
**Dataset:** Sample Superstore

The dataset contains retail transaction information, including:
- Order Date and Ship Date
- Customer Information
- Product Details
- Sales and Profit
- Quantity and Discount
- Category and Segment
- Region

## Data Cleaning & Preparation
- Used Power Query for data cleaning and transformation.
- Changed the Sales column data type to Decimal Number.
- Created a separate Date Table for time-based analysis.
- Added Year and Month Name columns.
- Prepared the data for interactive visualizations.

## Dashboard Features

### 1. Main Dashboard
- Total Sales by Year and Month
- Total Sales by Region
- Sales vs Target Achievement
- Top 5 Customers by Sales
- Year-over-Year Sales Comparison
- Top 5 Products by Sales
- Interactive slicers for Year, Segment, Region, and Category

### 2. Product Performance Analysis
A dedicated drill-through page to analyze individual product performance.

- Product Name and Product ID
- Total Quantity, Total Sales, and Total Profit
- Sales trend by Order Date
- Profit trend by Order Date
- Quantity trend by Order Date
- Sales performance by Region

### 3. Customer Insights
A dedicated drill-through page to understand individual customer purchasing patterns.

- Customer Name and Customer ID
- Total Quantity
- Average Order Value (AOV)
- Customer Sales History
- Product-wise Sales
- Profit by Category

### 4. Interactive Tooltip Analysis
A customized tooltip provides additional information when users interact with dashboard visuals.

- Sales comparison charts
- Total Sales
- Last Purchase Date
- Salesperson's Contribution

## Key Insights
- Identified top-performing products and customers based on sales.
- Compared sales performance across regions and business segments.
- Examined monthly and yearly sales patterns.
- Analyzed product-level sales, profit, and quantity performance.
- Explored customer purchasing patterns and profitability.

## Conclusion
This project demonstrates the use of Power BI for transforming retail data into meaningful business insights. Interactive dashboards, drill-through pages, customized tooltips, and data visualization techniques were used to support better business analysis and data-driven decision-making.
